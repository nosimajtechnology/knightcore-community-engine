# Canon policy

The Engine uses a default archetype without declaring a mascot.

1. A direct user instruction controls the requested output.
2. The latest approved project visual controls current state.
3. The locked Anchor Knight controls the default underlying silhouette and raw early-PS2 construction.
4. Approved Knightcore references control only their assigned roles.
5. Official/community-linked Knightcore material informs community grammar.
6. Original-PS2 references control rendering behaviors only.
7. New scene content is creative interpretation.

The bundled sheet may not be regenerated, enhanced, re-encoded, or replaced. Its hash is enforced in local validation and CI.

New community stories, guild members, locations, creatures, jokes, and armor variants remain unofficial unless an authorized Knightcore source establishes them. Game references never grant authority to copy characters, levels, HUDs, costumes, heraldry, enemies, or compositions.
