# Model-neutral animation packaging

Read this only when the user asks for animation, a final video prompt, or a named provider.

## Build the neutral brief first

Record:

- one-line setup and duration if supplied
- exact image/storyboard authority
- character and prop identities
- chronological shot/action progression
- camera movement and game-animation weight
- locked original-PS2 construction, lighting, bloom, and aspect ratio
- continuity-critical negatives
- audio instruction, including `NO MUSIC` when requested

Then adapt to the named provider without redesigning the scene.

## Delivery order

1. one-line setup
2. reference assignments
3. final copy-paste prompt
4. interface fields only when currently verified
5. exact measured character count when requested

Preserve in this order: approved archetype/project continuity; shot/action progression; PS2 geometry/material/light/bloom/camera; motion weight; decisive negatives; atmosphere and optional Tape layer.

Do not invent controls, field names, limits, or capabilities. If a provider behavior is unknown or variable, label it `unverified or variable` and use a generic image-to-video route. When the user supplies only a storyboard, treat it as the complete visual authority and do not request redundant uploads.

## Motion rules

Favor readable key poses, limited era-appropriate secondary motion, simple cloth/cape behavior, stepped game-animation weight, stable armor proportions, and camera motion that supports the approved composition. Prevent morphing plate parts, face exposure, chainmail animation, fused swords/shields, duplicated knights, modern motion blur, geometry upgrades, or new unapproved shots.
