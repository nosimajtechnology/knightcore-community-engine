# Quickstart

## Install

1. Download the latest `knightcore-community-engine.zip` from GitHub Releases. **Do not unzip it.**
2. In ChatGPT on the web, open **Plugins** → **Skills** → **Create** → **Upload from your computer**.
3. Upload the ZIP and start a new chat.

## Create

```text
Load the "Knightcore Community Engine" skill.
A faceless chrome knight quietly stocks a PS2 convenience store cart before a storm.
```

You can also name a mode:

```text
STILL: A chrome knight rests beside a river at night.
```

```text
CLASSIC CINEMATIC: A knight waits outside a boss door, decides not to enter, and walks toward sunrise instead.
```

The Engine finds appropriate original-PS2 visual references, builds the first frame, and asks for approval at the point where approval matters. You do not need to specify game titles or technical rendering language.

If the result is right, reply `Approved.` If one detail is wrong, name it plainly:

```text
The armor is too smooth. Restore the locked early-PS2 Anchor Knight construction and change nothing else.
```

For video, approve the image/storyboard and name your video model. The Engine prepares the copy-paste motion prompt; the separate video tool renders it.
